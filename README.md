# CyberGame iPhone File Viewers

CyberGame Limited publishes focused iPhone and iPad utilities for opening local files that iOS does not always preview well.

- Official publisher hub: https://cybergame.ai/
- Apple developer page: https://apps.apple.com/us/developer/cybergame-limited/id1778824442
- GitHub publisher profile: https://github.com/Fomod

## Html Preview

Open and render local `.html`, `.htm`, and `.xhtml` files from Files, Mail, downloads, cloud drives, ChatGPT, Claude, and other iOS apps.

- Official site: https://html.cybergame.ai/
- Open HTML on iPhone: https://html.cybergame.ai/open-html-file-iphone/
- App Store: https://apps.apple.com/app/id6760443436
- Official website repository: https://github.com/Fomod/html.cybergame.ai

## Md Preview

Open and render local `.md`, `.markdown`, `.mdx`, `.rmd`, and `.qmd` files, including code, tables, math, and Mermaid diagrams.

- Official site: https://markdown.cybergame.ai/
- Open Markdown on iPhone: https://markdown.cybergame.ai/open-markdown-file-iphone/
- App Store: https://apps.apple.com/app/id6760341080
- Official website repository: https://github.com/Fomod/markdown.cybergame.ai

Both apps have no subscriptions, no in-app purchases, and no ads.
